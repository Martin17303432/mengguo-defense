# 萌果守卫战

《萌果守卫战》是一款可爱的网页休闲小游戏：玩家通过交换 6x6 棋盘上的水果，触发三消和连锁消除，释放不同水果技能，击退从右侧靠近果园基地的小敌人。

## 在线发布

这个项目是纯前端单文件游戏，适合直接发布到 GitHub Pages、Netlify、Vercel 或 Cloudflare Pages。

GitHub Pages 推荐设置：

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ root`

发布后访问：

```text
https://你的GitHub用户名.github.io/仓库名/
```

## 游戏特色

- 6x6 水果交换消除棋盘
- 横向或纵向三个及以上水果即可消除
- 支持连锁消除、分数反馈和浮动文字
- 敌人从右向左进攻，玩家需要守护果园基地
- 10 个递进关卡，包含普通敌人、快速敌人、高血量敌人和 Boss
- 金币、升级、道具和 localStorage 存档
- 适配电脑和手机浏览器

## 水果效果

- 草莓：普通攻击
- 橙子：范围爆炸
- 西瓜：高伤害攻击
- 蓝莓：减速敌人
- 香蕉：获得额外金币

## 道具

- 炸弹果：清除一片水果，并对所有敌人造成伤害
- 冰冻果汁：让所有敌人停止移动 3 秒
- 阳光糖果：立即获得金币和能量

## 本地运行

最简单的方式是直接双击打开：

```text
index.html
```

如果浏览器限制本地文件，也可以启动本地服务器：

```powershell
node server.mjs
```

然后访问：

```text
http://127.0.0.1:4188/index.html
```

## 文件说明

- `index.html`：完整游戏代码，包含 HTML、CSS 和 JavaScript
- `server.mjs`：本地预览用的小型静态服务器，发布到 GitHub Pages 时不需要

## 存档说明

游戏会使用浏览器 `localStorage` 保存：

- 最高关卡
- 金币
- 升级等级
- 道具数量
- 历史最高分

清除浏览器站点数据会重置存档。
